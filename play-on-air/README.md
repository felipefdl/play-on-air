# PlayOnAir

Chromecast devices as AirPlay 2 speakers on the local network.

PlayOnAir discovers Google Cast devices, advertises each as an AirPlay 2 receiver, and bridges audio from iPhone, iPad, or Mac. No accounts and no cloud.

**Requires host network** so mDNS discovery and AirPlay/Cast traffic work on the LAN.

See [DOCS.md](DOCS.md) for install steps and limits.
